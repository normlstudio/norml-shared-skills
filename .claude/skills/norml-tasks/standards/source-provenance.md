# Preserve original requests

Before creating or materially amending a task, retain its source. Task wording
may be refined; the original remains available for comparison.

## Direct input

Save the exact message under the resolved owner's
`captures/yyyy-mm-dd-descriptive-topic.md`, including short requests. Add a
collision suffix when needed; never overwrite an earlier capture. One request
may source many tasks. Record author, known date/time, original language or
languages, source kind and any available stable message URL or ID. If no stable
URL/time is exposed, say so; the local capture is the durable pointer.

Put the verbatim text under `## Original request`. Preserve dictation errors,
spelling and the original language. Put cleaned wording, translations,
interpretation and a disposition table in separate sections. Never call a
translation or reconstructed summary verbatim. Redact credentials if present
and label the omission; secret preservation belongs to `norml-security`.

Each new or amended task's `## Source` links this original-request anchor and
names its language and date. The capture maps meaningful requests to task IDs,
decisions or explicit deferrals. Add later corrections as new captures and
append source links to the same task, preserving earlier intent and history.

## Meetings and existing records

Meeting transcripts go through the configured canonical meeting archive first. Link the canonical archived
transcript, meeting identity and known timestamp/section directly from the task;
do not duplicate a full transcript in captures. A capture may hold a pointer and
disposition mapping. An existing durable request in another authorized owner is
also linked, not silently copied into a competing source archive.

Use portable workspace-relative paths or repository links across owners. Preserve
confidential source access: public issues receive accepted scope and an honest
source pointer/access note, never a private transcript copied into their body.

## Existing tasks

Apply this rule on new work and when a task receives a new request. Backfill
historical originals only from verified records when available; do not perform
an unrelated bulk migration. Label missing historical originals as unavailable
and retain existing source evidence. Never synthesize what someone “must have
said.” A task stays discoverable even when its original cannot be recovered.

## Verification

Confirm the source exists, the task link resolves, original language is recorded,
the original is distinguishable from refinement, and every request has a
disposition. For meeting links, confirm the referenced archive identity. The
planning helper's structural checks alone do not verify source fidelity.
