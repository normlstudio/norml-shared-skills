# Audit acceptance

- [ ] Exact scope/canonical/CMS/locales and crawl rate/access recorded.
- [ ] Every eight-area check has evidence/status or a justified N/A/blocked result.
- [ ] Full vs sampled coverage, caps and failed sources disclosed.
- [ ] Lab/field and URL/origin/device data are distinguished.
- [ ] Findings cite real data/reproduction with dates, not guessed totals.
- [ ] No fabricated health score, cost/time estimate or named assignee.
- [ ] All six report sections exist with unified severity counts.
- [ ] Public-source evidence and provider-indexed evidence are separate.
- [ ] Current schema/search eligibility checked; no retired-feature promise.
- [ ] Report written/read back with history preserved and no secret values.
- [ ] No site/provider mutation during the audit.
