# Schema acceptance

- [ ] Target/CMS/query/owner verified; audit mode made no live changes.
- [ ] All dynamic fields have source, visibility and missing-value rules.
- [ ] Zero coordinates/prices/days are preserved when meaningful.
- [ ] No fake reviews, addresses, stock, policy terms or identity facts.
- [ ] PHP APIs exist or are guarded; correct theme/plugin loader used.
- [ ] JSON script output encodes HEX_TAG/AMP/APOS/QUOT and closes safely.
- [ ] Field schemas, getters and rendered output agree for populated/empty states.
- [ ] Stable IDs refer to real distinct entities; reference-only nodes aren't duplicates.
- [ ] Local validator and actual external checks are labeled by what they prove.
- [ ] Google feature claims use current primary guidance; FAQ/search-box retired.
- [ ] Actual production output inspected after any authorized deployment.
- [ ] GSC evidence dated by indexed last crawl, not advertised as a live fetch.
