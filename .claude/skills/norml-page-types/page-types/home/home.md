# Home

Family ID: `home`. This overview describes the entire set of related pages.
Member files are flat siblings; actual project pages are instances of these specs.

## Purpose and fit

Every public informational site needs a primary orientation and onward navigation.

**Skip or use another family:** Do not invent a collection of homepages; campaign pages belong to utility or an approved project-specific family.

## Canonical entity and model

The website as a whole.

Singleton; a posts-index front page is a documented project alternative.
This is candidate modeling guidance; `WordPress architecture review` owns the actual
WordPress primitive. Match an inherited model before proposing another one.
