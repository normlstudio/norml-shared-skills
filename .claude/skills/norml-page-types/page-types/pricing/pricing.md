# Pricing and plans

Family ID: `pricing`. This overview describes the entire set of related pages.
Member files are flat siblings; actual project pages are instances of these specs.

## Purpose and fit

Visitors need a public explanation of approved pricing, plans or package differences.

**Skip or use another family:** Architecture is not authorization to invent prices; a quote-only service can use an enquiry route instead.

## Canonical entity and model

Approved commercial plans or package definitions.

Singleton comparison hub, with plan singles only when each has substantive independent content.
This is candidate modeling guidance; `WordPress architecture review` owns the actual
WordPress primitive. Match an inherited model before proposing another one.
