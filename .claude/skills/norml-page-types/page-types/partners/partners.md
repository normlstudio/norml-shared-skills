# Partners and affiliations

Family ID: `partners`. This overview describes the entire set of related pages.
Member files are flat siblings; actual project pages are instances of these specs.

## Purpose and fit

The organization has verified relationships that matter to visitors.

**Skip or use another family:** A customer logo, technology used or membership badge is not automatically a partner.

## Canonical entity and model

One verified partner/affiliation with the relationship kind recorded.

Collection if repeatable; may stay embedded in About Us for a small set.
This is candidate modeling guidance; `WordPress architecture review` owns the actual
WordPress primitive. Match an inherited model before proposing another one.
