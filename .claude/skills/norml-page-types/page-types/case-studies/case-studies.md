# Case studies and work

Family ID: `case-studies`. This overview describes the entire set of related pages.
Member files are flat siblings; actual project pages are instances of these specs.

## Purpose and fit

The organization has attributable projects or customer stories that show its work.

**Skip or use another family:** Do not turn unverified testimonials or hypothetical outcomes into case studies.

## Canonical entity and model

One real project/customer story; optional classifications by industry, offer or project kind.

Repeatable collection with archive and singles; classification can reuse shared industries/services.
This is candidate modeling guidance; `WordPress architecture review` owns the actual
WordPress primitive. Match an inherited model before proposing another one.
