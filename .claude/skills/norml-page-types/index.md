# Page types — complete index

Each row names a **family**, not one page. Read its overview and selected member
files before recommending architecture. Every route is illustrative. Families
are options; neither this inventory nor its branches mandate pages for a client.

Use [SKILL.md](SKILL.md) for selection/handoff and [add-page-type.md](add-page-type.md)
for additions. Shared meaning and multiplication gates live in
[architecture principles](standards/architecture.md).

## Shared ownership of intersections

Industry × service is owned by [industries/industry-by-service](page-types/industries/industry-by-service.md).
Service × location is owned by [services/service-by-location](page-types/services/service-by-location.md).
Coverage/industry/service hubs link to these same records. Reverse route
orientation never creates a second canonical page or member definition.

About Us is [about-us/archive](page-types/about-us/archive.md), with
[team-member singles](page-types/about-us/single.md); a dedicated team
directory is optional. Archive labels and CMS primitives are independent.
